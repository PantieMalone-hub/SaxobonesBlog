=== Lancer (spade) Cursor Set ===

Author's description:

Ever wanted a cursor set about an mischievous boy
who's dad is a tyrannical king? Well here you go!
Includes most cursor sets, with a spade as a pointer and Mr.Generosity himself spinning as busy and working in background!

Some cursors and character this cursor is themed on is made by Toby Fox.
